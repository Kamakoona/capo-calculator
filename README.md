# 카포 계산기

악보(코드보) 사진을 올리면 브라우저에서 코드를 자동으로 인식하고, 원하는 다른 코드 모양으로
연주할 수 있도록 **카포 위치와 바뀐 코드 진행**을 계산해 주는 웹 앱입니다.

- 첫 마디 코드를 원하는 코드 모양으로 지정하면, 같은 음이 나도록 카포 프렛을 계산합니다.
- 이어지는 모든 코드도 같은 만큼 자동으로 변환해서 보여 줍니다.
- 업로드한 이미지와 코드 인식(OCR)은 **서버로 전송되지 않고**, 브라우저 안에서만 처리됩니다.

## 로컬 실행 (Windows)

`run.bat`을 더블클릭하세요.

또는:

```bash
python -m venv .venv
.venv\Scripts\activate      # Windows; use `source .venv/bin/activate` on Linux/macOS
pip install -r requirements.txt
uvicorn app.main:app --host 127.0.0.1 --port 8001
```

브라우저: http://127.0.0.1:8001

## Render 클라우드

프론트엔드만 클라우드에 올려도 됩니다. 이미지 업로드와 코드 인식은 접속한 PC의 브라우저에서
수행됩니다.

1. GitHub 저장소를 Render Blueprint로 배포
2. 배포된 주소로 접속
3. **악보 사진 업로드** → 코드 인식 → 카포 계산

## 사용법

1. 악보(코드보) 사진을 업로드하고 **코드 인식**을 누릅니다.
2. 인식된 코드 목록을 확인하고, 틀린 부분은 직접 고치거나 지울 수 있습니다.
   사진 없이 **직접 입력**으로 코드를 타이핑해도 됩니다.
3. 첫 마디를 연주하고 싶은 코드 모양을 입력하고 **카포 계산**을 누릅니다.
4. 카포 프렛 위치와, 그 프렛에서 연주할 새 코드 진행이 표시됩니다.

## 참고

- 코드 인식(OCR)은 참고용입니다. 손글씨나 복잡한 배치는 정확하지 않을 수 있으니
  목록에서 직접 수정해 주세요.
- 코드 표기는 `C`, `Am7`, `G/B`, `D7sus4` 처럼 일반적인 팝/가요 코드보 표기를 지원합니다.
