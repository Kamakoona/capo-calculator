카포 계산기

악보(코드보) 사진을 올리면 브라우저에서 코드를 자동으로 인식합니다. 첫 마디 코드를 원하는 다른 코드 모양으로 지정하면, 같은 음이 나도록 카포 위치를 계산하고 이어지는 코드도 함께 바꿔 드립니다. 이미지는 서버로 업로드되지 않고 브라우저 안에서만 처리됩니다.

1. 악보 사진 업로드 (PNG / JPG)

사진 속 코드 글자(C, Am7, G/B 같은 표기)를 인식해 아래 목록에 순서대로 채워 넣습니다. 손글씨나 복잡한 배치는 인식이 정확하지 않을 수 있어 아래에서 직접 수정할 수 있습니다.

또는 코드를 직접 입력
기존에 인식된 코드 목록을 통째로 대체합니다.
2. 코드 순서 확인 · 수정

칸을 클릭해 코드를 고치거나, × 로 지울 수 있습니다. 순서가 곧 연주 순서입니다.
